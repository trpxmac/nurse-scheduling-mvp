# 🏥 Nurse Scheduling MVP — ระบบจัดเวรพยาบาลอัจฉริยะ

ระบบเว็บแอปพลิเคชันต้นแบบสำหรับช่วยจัดตารางเวรพยาบาลรายเดือนอัตโนมัติ โดยคำนึงถึงเงื่อนไข ข้อจำกัด และโควตาเวรต่าง ๆ เพื่อความสะดวกรวดเร็วในการทำงานของหัวหน้าตึกพยาบาล พัฒนาด้วย React, Vite และ Vanilla CSS

---

## ⚙️ ฟีเจอร์หลักของระบบ (Key Features)

1. **ระบบจัดการข้อมูลเจ้าหน้าที่ (Staff Management)**
   - เพิ่ม แก้ไข ลบ รายชื่อและข้อมูลพยาบาลในตึก

2. **ระบบตั้งค่าประเภทเวร (Shift Types)**
   - กำหนดช่วงเวลาเวร เช่น เวรเช้า, เวรบ่าย, เวรดึก, และวันหยุด

3. **ระบบจัดเวรด้วย AI (AI Auto-Scheduling)**
   - คำนวณจัดเวรรายเดือนอัตโนมัติตามกฎเกณฑ์พื้นฐาน

4. **ปฏิทินตารางเวร (Monthly Roster View)**
   - แสดงตารางเวรรายเดือนและสถิติเวรของพยาบาลแต่ละคน

5. **พิมพ์ตารางเวร (Print & Export)**
   - จัดรูปแบบสวยงามสำหรับการสั่งพิมพ์ออกเป็นกระดาษหรือบันทึกเป็น PDF

---

## 🚀 วิธีการติดตั้งและรันโปรเจกต์ (Getting Started)

### 1. ติดตั้ง Library/Dependencies
```bash
npm install
```

### 2. รันระบบในโหมดพัฒนา (Development)
```bash
npm run dev
```

### 3. บิลด์โปรเจกต์สำหรับใช้งานจริง (Production Build)
```bash
npm run build
```
